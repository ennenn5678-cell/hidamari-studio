プライバシーポリシー

最終更新日: 2026年10月7日

このポリシーは、ひだまりスタジオの内部用ツール「Hidamari Uploader」（以下「本ツール」）での情報の扱いを定めるものです。

1. 本ツールの目的

本ツールは、ひだまりスタジオが運営する自分たちの YouTube チャンネルに、自分たちで制作した動画をアップロードするためだけに使います。一般の方には提供していません。

2. 利用する Google のデータ

  • YouTube への動画のアップロード（https://www.googleapis.com/auth/youtube.upload）
  • アップロード先チャンネル名の確認（https://www.googleapis.com/auth/youtube.readonly）

これ以外の Google アカウントの情報（メール、連絡先、ファイルなど）にはアクセスしません。

3. 保存と共有

認証の情報は、本ツールを動かすコンピューターの中だけに保存し、第三者に共有・販売することはありません。視聴者の個人情報を集めることもありません。

4. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）からいつでも取り消せます。

本ツールによる Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. お問い合わせ

hidamari.anime.studio@gmail.com

Privacy Policy (English)

Hidamari Uploader is an internal tool used only by Hidamari Studio to upload its own videos to its own YouTube channels. It uses the YouTube upload scope and the read-only scope to confirm the target channel, and nothing else. Credentials are stored only on the studio's own computer and are never shared or sold. No viewer data is collected. Access can be revoked at any time at https://myaccount.google.com/connections. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: hidamari.anime.studio@gmail.com
